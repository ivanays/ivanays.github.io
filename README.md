Сайт для кабинета аппаратной косметологии.

О проекте

Сначала, это был  заказ. Затем, я продолжил его реализацию как свой пет-проект. Дизайн от Евгении Иванайской (https://vk.ru/ohjeni). Использовал сборщик Webpack 5 для совместной работы Pug, Sass, JavaScript, React и Markdown. Попрактиковался с SVG (файл, код, анимация). Ресурс проекта: https://github.com/ivanays/snv-react.local. Developer-версия сайта (2025г) выложена здесь: https://ivanays.github.io. Она больше про видение дизайнера и веб-разработчика, чем аналитика и маркетолога. Это поправлю.
