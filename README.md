Сайт для кабинета аппаратной косметологии.

О проекте

Сначала, это был не востребованный  заказ. Затем, я продолжил его реализацию как свой пет-проект. Дизайн от Евгении Иванайской (https://vk.ru/ohjeni). Использовал сборщик Webpack 5 для совместной работы Pug, Sass, JavaScript, React и Markdown. Попрактиковался с SVG (файл, код, анимация). Сайт адаптивен, согласно сетки Bootstrap. Ресурс проекта: https://github.com/ivanays/snv-react.local. В проекте предусмотрено создание админ-панели (CMS) для управлением контентом. Эта версия 2025 года.
